# الجهيني للتطوير العقاري | El Geheny Real Estate Development

موقع ويب احترافي وفخم لشركة **الجهيني للتطوير العقاري** بتصميم Luxury Real Estate يعكس القوة والخبرة والثقة منذ عام 1990.

## ✨ المميزات

- **تصميم فخم (Luxury)** بألوان داكنة (Navy) مع لمسات ذهبية وبيضاء و Glassmorphism.
- **عناصر ثلاثية الأبعاد (3D)** باستخدام `Three.js` + `@react-three/fiber` + `@react-three/drei` في الـ Hero والخلفيات مع حركة كاميرا عند التمرير.
- **أنيميشن سلس** باستخدام `Framer Motion` (انتقالات صفحات، ظهور تدريجي، أعداد متحركة، تأثيرات Tilt و Hover ثلاثية الأبعاد).
- **Responsive بالكامل** (موبايل – تابلت – ديسكتوب) عبر `Tailwind CSS`.
- **صفحات متعددة** عبر `React Router` مع تحميل مؤجل (Lazy Loading) للصفحات.
- **محسّن للأداء**: تقسيم الحزم (code-splitting)، Lazy loading للصور، تقليل عناصر 3D على الموبايل، واحترام `prefers-reduced-motion`.
- **دعم كامل للغة العربية** واتجاه RTL.

## 📄 الصفحات

| الصفحة | المسار | الوصف |
|--------|--------|-------|
| الرئيسية | `/` | Hero ثلاثي الأبعاد، إحصائيات متحركة، لماذا الجهيني، الرؤية، عرض المشاريع |
| من نحن | `/about` | الخط الزمني للشركة، القيم، الرؤية والرسالة |
| المشاريع | `/projects` | شبكة المشاريع مع فلاتر تفاعلية |
| تفاصيل المشروع | `/projects/:id` | الموقع، المميزات، نسبة الإنجاز، المعرض، طرق السداد، نموذج الحجز |
| المدونة | `/blog` | شبكة مقالات عقارية |
| تفاصيل المقال | `/blog/:id` | محتوى المقال الكامل |
| تواصل معنا | `/contact` | نموذج تواصل، بيانات الشركة، خريطة، واتساب |

## 🛠️ التقنيات المستخدمة

- React 18 + Vite
- Three.js / @react-three/fiber / @react-three/drei
- Framer Motion
- Tailwind CSS
- React Router DOM

## 🚀 التشغيل

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build

# معاينة نسخة الإنتاج
npm run preview
```

بعد تشغيل `npm run dev` افتح المتصفح على العنوان الذي يظهر في الطرفية (عادةً `http://localhost:5173`).

## 📁 هيكل المشروع

```
src/
├── components/      # مكونات قابلة لإعادة الاستخدام (Navbar, Footer, ProjectCard, ...)
├── pages/           # صفحات الموقع (Home, About, Projects, Blog, Contact, ...)
├── sections/        # أقسام الصفحة الرئيسية (Hero, Stats, WhyUs, Vision, ...)
├── three/           # مشاهد ثلاثية الأبعاد (CityScene, FloatingShapes)
├── hooks/           # React Hooks مخصصة (useCountUp, useMediaQuery)
├── data/            # بيانات الموقع (المشاريع، المقالات، معلومات الشركة)
├── App.jsx          # التوجيه والتخطيط العام
├── main.jsx         # نقطة الدخول
└── index.css        # أنماط Tailwind العامة
```

## 📝 ملاحظات

- الصور المستخدمة حالياً من Unsplash كصور توضيحية ويمكن استبدالها بصور المشاريع الفعلية من ملف `src/data/projects.js`.
- بيانات الشركة (الهاتف، البريد، العنوان، روابط التواصل) قابلة للتعديل من ملف `src/data/site.js`.
- نماذج التواصل والحجز حالياً تعمل في الواجهة فقط (Frontend)؛ يمكن ربطها بخدمة backend أو بريد إلكتروني عند الحاجة.
